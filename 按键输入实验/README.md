# 按键输入实验

## 硬件

| 项目 | 说明 |
|------|------|
| KEY0 引脚 | UART1_CTS_B → GPIO1_IO18 |
| 按下 | 低电平（`gpio_pinread == 0`） |
| 松开 | 高电平（`gpio_pinread == 1`） |

## 程序逻辑

- LED（GPIO1_IO03）以固定频率闪烁
- 按下 KEY0 → 蜂鸣器状态翻转（响/停切换）

## 与之前实验的区别

| | LED/蜂鸣器 | 按键 |
|------|-----------|------|
| GPIO 方向 | 输出 | **输入** |
| 读/get | 无 | `gpio_pinread()` 返回引脚电平 |
| 消抖 | 无 | 延时 10ms + 二次确认 |
| 电平判断 | 主动写 | 被动等 |

## 新引入的文件

| 文件 | 作用 |
|------|------|
| `bsp/gpio/bsp_gpio.c/h` | GPIO 通用操作：init/read/write |
| `bsp/key/bsp_key.c/h` | 按键驱动：消抖 + 值返回 |

## 按键消抖

```
检测到低电平
  → delay(10ms)
  → 再次检测
    → 仍是低电平 → 确认按下
    → 已恢复高电平 → 误触发（抖动）
```
