# C 语言版 LED 驱动实验

从汇编过渡到 C 语言，用 C 控制 i.MX6ULL GPIO 点亮 LED。

## 与汇编版对比

| | 汇编版 | C 语言版 |
|------|--------|----------|
| 主逻辑文件 | `led.s` | `main.c` |
| 启动文件 | `startup.s`（设栈+跳转） | `startup.s`（设栈+清零 bss+跳转 main） |
| 寄存器操作 | 手写 LDR/STR | C 语言指针访问绝对地址 |
| 可读性 | 差 | 好 |

## C 语言操作寄存器的本质

```c
// 汇编：ldr r0, =0x0209C004; ldr r1, [r0]; orr r1, r1, #8; str r1, [r0]

// C 语言：直接对绝对地址读写
unsigned int *p = (unsigned int *)0x0209C004;
*p |= (1 << 3);   // bit3 置 1
```

## 为什么还需要 startup.s？

| startup.s 的职责 | 说明 |
|------------------|------|
| 设置 SP 栈指针 | C 语言函数调用、局部变量都需要栈 |
| 清零 .bss 段 | C 语言未初始化的全局变量必须为 0 |
| 跳转到 main() | 把控制权交给 C |

> C 语言运行环境 = SP 指针 + bss 清零，缺一不可。

## 文件说明

| 文件 | 作用 |
|------|------|
| `startup.s` | 汇编启动：设栈、清零 bss、跳转 main |
| `main.c` | C 语言 LED 初始化和闪烁逻辑 |
| `Makefile` | 编译链接 |
