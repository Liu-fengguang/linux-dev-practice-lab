# 编译程序与链接

## 一、编译流程

| 步骤 | 工具 | 输入 → 输出 |
|------|------|-------------|
| ① 编译 | `arm-linux-gnueabihf-gcc -c` | `.c` `.s` → `.o` |
| ② 链接 | `arm-linux-gnueabihf-ld` | 所有 `.o` → `.elf` |
| ③ 格式转换 | `arm-linux-gnueabihf-objcopy` | `.elf` → `.bin` |
| ④ 反汇编 | `arm-linux-gnueabihf-objdump` | `.elf` → `.dis` |

```bash
# ① .s → .o
arm-linux-gnueabihf-gcc -c led.s -o led.o

# ② .o → .elf
arm-linux-gnueabihf-ld -Tled.lds led.o -o led.elf

# ③ .elf → .bin
arm-linux-gnueabihf-objcopy -O binary led.elf led.bin

# ④ .elf → 反汇编
arm-linux-gnueabihf-objdump -D led.elf > led.dis
```

## 二、链接

链接就是把所有 `.o` 文件拼在一起，并指定代码存放在内存的哪个位置。

### 链接起始地址

链接起始地址 = 代码运行时的起始地址。

对于 i.MX6ULL，RAM 有两块：

| RAM 类型 | 地址范围 | 大小 |
|----------|----------|------|
| 内部 RAM (OCRAM) | `0x00900000` ~ `0x0091FFFF` | 128KB |
| 外部 DDR（512MB） | `0x80000000` ~ `0x9FFFFFFF` | 512MB |
| 外部 DDR（256MB） | `0x80000000` ~ `0x8FFFFFFF` | 256MB |

本实验链接起始地址：**`0x87800000`**（DDR 范围内）。

### 为什么放 DDR 但还没初始化 DDR？

i.MX 系列芯片的 bin 文件**不是直接运行的**：

```
SD卡/EMMC
  └── bin 文件头部（含 DDR 初始化参数）
         │
    i.MX Boot ROM
         │
    ① 读取头部信息
    ② 根据头部参数初始化 DDR
    ③ 将 bin 文件拷贝到链接地址处
    ④ 跳转到链接地址开始执行
```

> bin 文件的**运行地址必须等于链接起始地址**（位置无关代码除外）。如果不一致，代码里的绝对地址跳转会跑飞。
